From the detector to the refined structure

Two free desktop tools for neutron diffraction users. PANDA opens the NeXus files straight from the instrument and turns them into clean, normalised patterns. Edit_PyCR builds and runs the FullProf refinement that comes next.

Workflow

One path from beamtime to results

The two programs cover consecutive steps of a powder diffraction experiment. PANDA's exported .xys files and buffer.buf list feed Edit_PyCR directly. The pyPRF viewer inside PANDA shows the FullProf fits.

  1. 1

    Measure

    NeXus files from D20, D1B, D2B, D16 or XtremeD, read while the experiment is still running.

  2. 2

    Reduce & inspect PANDA

    Normalise, combine, subtract and follow the patterns in temperature. Then export them for refinement.

  3. 3

    Refine Edit_PyCR

    Build the .pcr from a CIF, set up the model, run FullProf and compare the runs.

  4. 4

    Present pyPRF

    Turn Rietveld plots and refinement reports into publication-quality figures.

Powder Analysis for Neutron Diffraction Applications

PANDA v1.0.65

A data browser and reduction tool for neutron powder diffraction. Point it at the experiment's data folder and every numor appears with its temperature and comments. Select a few to overlay them, or a whole ramp to see it as a temperature map. From there you can combine, subtract, correct and export patterns ready for Rietveld refinement.

It is built for use during the experiment as well as after it. Ctrl+R picks up new numors as the instrument writes them, so the data can be followed live from the cabin or from home.

See a whole ramp at once

1D overlays for a few patterns, and a 2D map of intensity against 2θ or Q and temperature for many. A slice panel shows the pattern under the cursor. 3D surface and waterfall views are also available.

Combine and subtract

Sum or average equivalent scans. Subtract a paramagnetic reference from every pattern of a ramp in one step. Statistical uncertainties are propagated through every operation.

Background subtraction

Seven estimators: arPLS, AsLS, SNIP, rolling ball, Bruckner, Chebyshev with editable anchor points, and spline. A live preview shows the result, and one setting is applied to the whole block.

Peak fitting

Fit Gaussian peaks interactively, then propagate the model over the series. Integrated intensity, position and width are plotted against temperature, with a quality marker on every point.

2D detectors

For D2B, D16 and XtremeD: a frame-by-frame viewer and virtual-detector reconstruction. The detector images can be re-integrated with your own window and mapping mode.

Export for refinement

Export .xys files one per pattern, averaged over a temperature window or in blocks of N. A buffer.buf list for FullProf sequential refinement is written alongside.

Using PANDA

Getting started

A typical session in seven steps. Each step is covered in detail in the PANDA user manual.

  1. Configure the experiment

    The configuration window opens at start-up. Choose the instrument, the project folder and the data folder with the .nxs files. Set the normalisation (by monitor is recommended), binning and an optional calibration file. The settings are saved in user_config.py in the project folder and restored next time.

  2. Browse the numors

    All files are listed with numor, temperature and comment. Click a column header to sort, and right-click it to show more metadata. Spy mode shows every column, and the filter box accepts Boolean expressions (FeWO4 AND 300). Cells are editable with F2.

  3. Look at the data

    Hover over a numor to preview it. Select a few for a 1D overlay; the scroll wheel adds a vertical offset. Select more than five and the view becomes a 2D heatmap. Switch the axis between 2θ and Q, use a log scale for weak reflections, or open the 3D views.

  4. Process

    Combine (Ctrl+A) sums or averages equivalent scans. Difference (Ctrl+D) subtracts the second pattern from the first. With more than two selected, it subtracts a chosen baseline from all of them. The background tool corrects a whole ramp with the same settings. Results go to their own workspace, and the raw data are never modified.

  5. Fit peaks

    With one pattern selected, press Fit. Click either side of a peak to set the background, then click the peak to add a Gaussian. Sequential Fit applies the model to every visible pattern and saves the results to the working folder.

  6. Export

    Export patterns writes .xys files one per pattern, averaged over a temperature window, or in blocks of N. Use a filename prefix and Fix 2θ for sequential refinements. Export figure saves PNG, PDF or SVG, and Save log records the dataset list.

  7. Check the refinement

    The pyPRF button opens the FullProf result viewer. In Live mode it reloads the .prf each time FullProf rewrites it, so a refinement can be followed while it runs.

Common scientific workflows

Finding a phase transition
  1. Load the full temperature series and select all numors: the view switches to a 2D heatmap.
  2. Look for peaks that split, shift, appear or lose intensity with temperature.
  3. Switch the colour scale to logarithmic to reveal weak or diffuse features.
  4. Open the slice panel to read individual temperatures directly on the map.
Isolating magnetic reflections
  1. Select a pattern below the ordering temperature, then Ctrl+click a reference above it.
  2. Press Ctrl+D: the difference keeps only the magnetic contribution, with propagated errors.
  3. For a whole ramp, select all numors plus the reference and choose it as the baseline. You get one difference per temperature, ready to plot as a heatmap.
  4. Check that both patterns have comparable statistics and normalisation before interpreting weak signals.
Preparing data for FullProf
  1. Select equivalent measurements (same sample, temperature and configuration) and combine them.
  2. Check the combined pattern visually, then export it as .xys.
  3. For a series, export with a prefix such as MySample_ramp. PANDA numbers the files _001 … _999 and writes buffer.buf for FullProf's sequential mode.
  4. After refining, open the .prf in pyPRF to inspect and export the fit.

FullProf PCR editor

Edit_PyCR v0.4.0

A dedicated editor for FullProf .pcr files. It knows which numbers are refinement codes, where each phase and pattern begins, and what every keyword means. You spend less time counting columns and more time refining.

It does not replace FullProf. fp2k and FullProf's own converters still do the calculation. Edit_PyCR handles everything around them: setting up the file, running it, and keeping track of what each run changed.

Structure tree

An outline of experiments, phases, background, excluded regions, constraints and restraints. Right-click any block for the right editor, and drag phases between files.

Guided dialogs

Atoms (including anisotropic ADPs and magnetic moments), cell, profile, instrument parameters and .irf files, background points and global VARY/FIX commands. Each value has its own Refine box.

New files in seconds

Build a .pcr from a CIF or magnetic CIF with FullProf's own converters, or start from a catalogue of real example files. Several files can be merged into one multi-phase or multi-pattern refinement.

Run and compare

Run FullProf with a live quality display for each cycle, then accept or discard the result. A history chart tracks χ², R-factors and cell parameters over the accepted runs.

Strategies & series

Release parameters in stages instead of all at once. Refine a numbered series of data files in sequence, each run starting from the previous result.

An editor that knows the format

Highlighting that tells fixed values from refined codes, keyword tooltips from the FullProf documentation, folding, column selection and one-click renumbering of parameters.

Using Edit_PyCR

A typical refinement

The usual order of work. Any step can be revisited at any time. The Edit_PyCR user manual describes every menu, panel and dialog.

  1. Start the file

    Open an existing .pcr (or drag it onto the window). Otherwise use Create: from a CIF, from an mCIF, from a template, or by combining open files into a multi-phase or multi-pattern refinement.

  2. Point it at the data

    Right-click the experiment in the tree and choose Set data file…. The pattern panel plots the raw data straight away, before any refinement.

  3. Background and excluded regions

    On that plot, Determine background… suggests background points automatically; left-click adds a point and right-click removes one. Define excluded regions… marks ranges with a double-click.

  4. Instrument and phases

    Check the wavelength and resolution function, or load an .irf from FullProf's library. Then edit cell parameters and atoms from the phase's right-click menu, or fill an empty phase from a CIF.

  5. Decide what refines

    Start with the scale and background. Build a Strategy to release the other parameters in stages. Link parameters under Constrained parameters, add linear restraints or box limits, and Auto-renumber to close numbering gaps.

  6. Run, compare, iterate

    Run FullProf, watch the live quality display, then Accept or Discard. The refinement history shows whether the run was better than the last one. Once the model works, Sequential applies it to a whole series.

Refinement codes, briefly

Every refinable value in a .pcr is followed by a code:

0
fixed: the value is never changed
1.00
“refine this”: FullProf assigns the number itself (Aut=1)
21.00
parameter 2 with multiplier 1. Codes sharing a number refine together, and a negative multiplier moves the other way

Edit_PyCR writes these codes for you. Constraints, restraints and box limits refer to plain parameter numbers, and renumbering keeps them all consistent.

Safe by design

  • Check this file runs FullProf on a throwaway copy, so your file and its outputs are never touched.
  • Discard puts back the file exactly as it was before the run.
  • The history keeps only the runs you accepted, and any of them can be reloaded.
  • Refinement summary lists every refined value with its esd and the Bragg R-factors.
  • Kill fp2k stops a FullProf run that has hung.

PANDA 1.0.6428 Sep 2026
  • NewPretreated 1D data in .xy files (2θ and intensity only) can be loaded; uncertainties are estimated as √I, with a minimum of 1 count.
  • NewD2B virtual detector: the save dialog can export the image as XYZS or Origin ASCII (γ, vertical pixel, counts), as the heatmap already could.

  • ImprovedD16 and XtremeD uncertainties use the error of the mean over the pixels of each 2θ channel instead of their spread, which overestimated them.
